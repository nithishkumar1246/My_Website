NeuroScan MRI Analyzer

PyTorch • U-Net • ResNet34 • OpenCV • Albumentations

Overview

NeuroScan is a computer vision segmentation tool built to outline brain abnormalities in clinical MRI scans. Utilizing a custom U-Net architecture with a ResNet34 encoder, it achieves a Dice Coefficient of 0.88 on validation datasets.

Key Features

  • Pixel-level semantic segmentation of tumors and lesions.
  • Optimized image preprocessing pipeline using CLAHE and OpenCV.
  • Model explainability using Grad-CAM class activation maps.
